# 【爱心浇灌，生命之花】北大医院庆祝5·12国际护士节“Nurses Week”系列活动拉开帷幕

> 更新时间：2026-09-11 (UTC+8)

北大医院庆祝5·12国际护士节“Nurses Week”系列活动

（请点击图片保存原图）
系列活动第一波~《百廿芳华 天使情怀》征文
——记录120位北大医院护理人的精彩护理人生故事

为庆祝北京大学建校120周年和5.12国际护士节，深刻领会“爱心浇灌，生命之花”的护理真谛，传播我院护理工作的人文情怀和专业品质，记录平凡中见伟大、细微中见真情的精彩护理人生故事，表达护士的情怀。护理部将启动《百廿芳华 天使情怀》征文活动，记录120位北大医院护理人的精彩护理人生故事，具体事宜如下：
**征文要求**
1. 参加人员：全院护士、离退休护士、在院护生及护士家属、患者等均可。

2. 征文内容：记录1位北大医院护理人的故事，既可以对某位护理前辈、某位老师的回忆；也可以记录自己工作生活中的真实故事、温情实际与特殊经历，体现对护士职业的理解和感触；还可以站在家属或者患者的视角诠释护理人的情怀，行文以第一人称或第三人称叙述。

3. 字数不限，体裁不限，随笔、漫画、散文、诗歌均可。

4. 作品须为原创和首发，事实客观，注明作者姓名、科室、病房及联系方式。
投稿时间及方式
1. 投稿方式：自愿参加，请各科室积极支持和鼓励护理人员参与此次活动。作品报送各科护士长，由科护士长进行初筛，统一填写2018 年《百廿芳华 天使情怀》征文作者信息表（见附件），同时将电子版作品（打包压缩）上交。

2. 投稿邮箱：m13910991977_1@163.com 

主题设置：科室-文章数-《百廿芳华 天使情怀》   

联系人：胥老师 李老师 陈老师   联系电话：83575148

3. 投稿时间：在职职工投稿自发通知之日起至5月11日17：00止；其他人员投稿自发通知之日起至5月20日17：00止。

4. 对征文进行评选，最终选出120篇有代表性的作品整理成册出版，并在相关宣传渠道和平台上连载。

5. 对组稿积极的科室以及作品优秀的个人给予表彰及奖励。
